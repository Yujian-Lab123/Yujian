# 遇见 · 产品逻辑（简版，完整见《总体概览》）

**一句话**：发现一个值得聊一句的人。

**顺序相反**：内容 → 共鸣 → 进一步了解 → 发现作者 → 想认识 → 双向同意 → 连接。先理解思想，再认识人。

**三层自我**：Long-term Self（知乎长期内容）× Present Self（此刻状态，短周期衰减）× Intent（明确连接意愿，不让 AI 猜）。

**不做**：人格测试、MBTI、灵魂契合度 %、头像墙、左右滑、Feed、群聊、自建聊天（连接后深链回知乎）。

**魔法时刻**：用户第一次看到陌生人的文章 + AI 解释“为什么是这个人” → “写这个的人是谁？”

**一级结构**：遇见 / 已遇见 / 我的（侧面 P9 再做）。

**页面链**：Landing → OAuth → AI 理解 → 推荐（Content Bridge 文章卡 + 为什么给你看）→ 了解作者（TA 还写过 / 交集 / 一个不同 / 开场问题）→ 想认识 → 反向发现（TA 先读你的内容）→ 双向成功 → 去知乎关注/私信。
